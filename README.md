# 🍛 Spice Route — Restaurant Ordering Website

A fully functional restaurant landing page with online ordering, cart system, checkout, and auto-WhatsApp order dispatch.

## 🔗 Live Demo

👉 **[View Live Site](https://spice-route-lahore.netlify.app/)**

## ✨ Features

- 🛒 Complete cart system (add/remove/quantity)
- 📝 Checkout form with COD/Card options
- 📱 Auto WhatsApp order to restaurant owner
- 🍽️ 50+ menu items with categories (Biryani, Karahi, BBQ, Fast Food, Dessert, Drinks)
- 🔍 Menu search functionality
- 📊 Auto tax and delivery calculation
- 💾 Cart saved in localStorage
- 🎨 Dark premium theme with smooth animations
- 📱 Fully responsive (mobile-first)
- ⚡ Scroll reveal and 3D card effects

## 🛠️ Tech Stack

- HTML5
- CSS3 (Custom animations, Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts (Inter + Playfair Display)

## 🚀 Run Locally

1. Clone this repository
2. Open `index.html` in your browser
3. That's it!
